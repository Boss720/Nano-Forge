# NanoForge Phase 6 Architectural Survey & Analysis Report
## Focus: Shared Memory (R1/R2) & Token/Latency Telemetry Subsystems

---

### Executive Summary

This report delivers the architectural analysis and implementation design for **Requirements R1 (Live E2E Swarm Playground)** and **R2 (Phase 6 Swarm Capabilities: Shared Memory & Token/Latency Telemetry)** in NanoForge.

The current NanoForge codebase contains a modular, high-integrity architecture:
1. **`packages/protocol`**: Pure isomorphic TypeScript/Zod wire contracts, lifecycle FSMs, and tool schemas (zero Node dependencies).
2. **`apps/agent-host`**: Authenticated Fastify WebSocket server, hierarchical supervisor tree (max depth 3, max concurrency 8), actor-model mailbox queues with SEC-SUB-03 authorization, Git worktree/scratch isolation, and daemon task supervisors with 5-field cron parsing.
3. **`src/`**: React 19 visual control plane with live tree visualization, tool inspection, mailbox accordions, and daemon managers.

To fulfill Phase 6 R1 and R2, we design:
- **Shared Memory Engine**: Cross-agent key-value store with namespace isolation (`global`, `swarm`, `agent:<id>`, `task:<id>`, `custom`), version tracking, TTL expiration, query pattern matching (glob/prefix/tags), real-time WebSocket change notifications, and LLM tool bindings (`memory.set`, `memory.get`, `memory.query`, `memory.delete`).
- **Token & Latency Telemetry Engine**: Per-agent and fleet-wide telemetry meters tracking prompt/completion tokens, calculated USD cost, tokens/sec throughput, turn execution latency, tool execution duration, moving averages, and p95 latency percentiles.

---

### 1. Requirements Deep Dive: R1 & R2

#### 1.1 Requirement R1: Live E2E Swarm Playground & Interactive Testing
- **Goal**: Connect the agent host server and visual control plane with interactive end-to-end swarm execution capabilities.
- **Key Capabilities**:
  - Live simulated and real subagent lifecycle turns.
  - Streaming tool inspections with real-time argument and output digests.
  - Real-time mailbox message exchanges with reactive zero-polling turn wakeups.
  - Background daemon process execution with interactive STDIN and circular ring buffer logs.
  - Real-time WebSocket synchronization across client and host without page reload or state desynchronization.

#### 1.2 Requirement R2: Shared Memory (`memory.set`, `memory.get`, `memory.query`)
- **Goal**: Provide cross-agent shared memory / key-value workspace context to enable multi-agent collaboration, shared blackboard architectures, and inter-agent knowledge accumulation.
- **Key Operations**:
  - **`memory.set`**: Write or update a key in a designated namespace. Supports metadata including `authorId`, `authorName`, `tags`, `ttlSeconds`, and automatic `version` incrementation.
  - **`memory.get`**: Retrieve a specific key from a namespace with full entry metadata (`value`, `version`, `createdAt`, `updatedAt`, `authorId`, `tags`).
  - **`memory.query`**: Search and filter memory entries using namespace scoping, key prefix / glob matching, tag intersection filtering, with pagination (`limit`, `offset`).
  - **`memory.delete`**: Explicit deletion of keys within an accessible namespace.
- **Namespace Sandboxing & Isolation**:
  - `global` / `default`: Accessible by all agents for workspace-wide discoveries and consensus.
  - `swarm` / `team`: Scoped to an active subagent tree or swarm coordination task.
  - `agent:<agentId>`: Agent-owned namespace where the owner has write access and peers have read access.
  - `private:<agentId>`: Private scratchpad memory accessible only to the owner agent.
- **Reactivity & Event Stream**:
  - Mutations emit wire events (`memory.entry_set`, `memory.entry_deleted`, `memory.cleared`, `memory.snapshot`) to broadcast live memory state across WebSocket connections to the UI.

#### 1.3 Requirement R2: Token Consumption & Runtime Latency Telemetry
- **Goal**: Detailed token metering and latency metrics collected in the host and displayed in the visual control plane.
- **Key Metrics**:
  - **Token Metrics**:
    - `promptTokens` (input tokens sent to provider)
    - `completionTokens` (output tokens generated by provider)
    - `totalTokens` (`promptTokens + completionTokens`)
    - `estimatedCostUsd` (computed from provider's `costPer1kInputTokens` and `costPer1kOutputTokens`)
    - `tokensPerSecond` (streaming throughput rate)
    - `turnCount` (number of completed LLM generation turns)
  - **Latency Metrics**:
    - `lastTurnLatencyMs` (duration of the most recent LLM turn)
    - `avgTurnLatencyMs` (mean turn latency across all turns)
    - `p95TurnLatencyMs` (95th percentile turn latency)
    - `totalDurationMs` (cumulative runtime from agent start)
    - `toolExecutionLatencyMs` (cumulative duration spent waiting on tool executions)
    - `uptimeMs` (total active elapsed time)
  - **Fleet-Wide Aggregations**:
    - Aggregation across all active and completed nodes in the hierarchy tree: total fleet tokens, total cost in USD, active subagent count, and fleet average latency.

### 2. Current Agent Host Architecture Analysis

#### 2.1 Tool Execution Architecture
The agent host executes tools via two primary pathways:
1. **Subagent & Daemon Lifecycle Tools** (`apps/agent-host/src/agents/tools.ts`, `apps/agent-host/src/daemons/tools.ts`):
   - Implements direct executor functions (`executeInvokeSubagentTool`, `executeManageSubagentsTool`, `executeSendMessageTool`, `executeDefineSubagentTool`, `executeScheduleTool`, `executeManageTaskTool`).
   - Parses inputs strictly with Zod schemas defined in `@protocol/subagents` and `@protocol/tasks`.
2. **Step Execution Pipeline in RunCoordinator** (`apps/agent-host/src/runs/coordinator.ts`):
   - Model outputs tool call proposals (`ProposedToolCall`).
   - Proposals are converted into structured `ToolRequest` objects and validated against the workspace security policy via `authorize(request, policy)`.
   - If verdict is `"ask"`, `SocketApprovalGate` pauses execution and sends `tool.approval_required` over WebSocket, resolving upon user grant/deny.
   - Execution runs via `runTerminalJob` (`TerminalJobHandle`) with timeout enforcement, child process tree termination, and output hashing (SHA-256 digests in event ledger, full logs to audit store).

#### 2.2 Actor Mailbox & Messaging Bus
Located in `apps/agent-host/src/agents/mailbox.ts`:
- **Queue Structure**: `Map<string, SubagentMessage[]>` maintaining per-recipient FIFO queues with priority ordering (`high` (weight 3) > `normal` (weight 2) > `low` (weight 1)).
- **Authorization Enforcement (`SEC-SUB-03`)**:
  - Senders may only send messages to:
    1. Direct parent (`recipientId === sender.parentId`)
    2. Direct children (`recipient.parentId === sender.id`)
    3. Siblings sharing the exact same parent (`recipient.parentId === sender.parentId`)
- **Audit Ledger**: All messages are recorded in an append-only ledger for post-mortem analysis.
- **Reactive Wakeups (`apps/agent-host/src/agents/wakeup.ts`)**:
  - `ReactiveWakeupEngine` emits `<system_notification>` blocks (`MESSAGE_RECEIVED`, `CHILD_COMPLETED`, `CHILD_ERRORED`, `TASK_COMPLETED`, `TIMER_EXPIRED`, `SENDER_TERMINATED`) to resume suspended agents without CPU spin or polling loops.

#### 2.3 Supervisor Tree & Lifecycle Management
Located in `apps/agent-host/src/agents/supervisor.ts`, `hierarchy.ts`, and `registry.ts`:
- **Hierarchy Constraints**:
  - Max recursion depth <= 3 (`MAX_SUBAGENT_HIERARCHY_DEPTH`) enforced by `HierarchyManager.validateSpawn()`.
  - Max concurrent active subagents <= 8 (`MAX_CONCURRENT_SUBAGENTS`).
- **Cascading Teardown**:
  - `killTree(rootId)` executes post-order traversal to abort turns, prune Git worktrees, kill creator-bound daemon tasks, cancel scheduled timers, and transition states to `errored`.
- **Registry & Liveness**:
  - `SubagentRegistry` indexes nodes by ID, parent ID, and archetype.
  - Periodic `livenessSweep(staleThresholdMs)` detects stale heartbeats and marks timed-out nodes.
- **Escalation Ladder**:
  - 5-rung resilient ladder (`Retry` -> `Replace` -> `Skip` -> `Redistribute` -> `Degrade`).

#### 2.4 WebSocket RPC & Wire Protocol
Located in `apps/agent-host/src/server.ts`, `protocol.ts`, and `session.ts`:
- **Fastify Server**: Binds strictly to `127.0.0.1` with single-use cryptographic token authentication.
- **Frame Decoding**: Inbound frames are validated via `decodeClientMessage()` using Zod discriminated unions.
- **Session Dispatching**:
  - Handles `workspace.*`, `plan.*`, `run.*`, `approval.*`, `subagent.*`, `task.*`, `schedule.*`, and `terminal.*` RPCs.
  - Forwards lifecycle events (`subagent.event`, `task.event`, `run.state`, `run.event`) to the connected UI socket.

#### 4.1 New File: `apps/agent-host/src/agents/memory.ts`
Implement `SharedMemoryEngine`:

```ts
import { EventEmitter } from "node:events";
import type {
  MemoryEntry,
  MemorySetParams,
  MemorySetResult,
  MemoryGetParams,
  MemoryGetResult,
  MemoryQueryParams,
  MemoryQueryResult,
  MemoryDeleteParams,
  MemoryDeleteResult,
  MemoryLifecycleEvent,
} from "@protocol/memory";

export interface SharedMemoryEngineOptions {
  workspaceRoot?: string;
  persistToFile?: boolean;
}

export class SharedMemoryEngine extends EventEmitter {
  private readonly entries = new Map<string, MemoryEntry>();

  private makeKey(namespace: string, key: string): string {
    return `${namespace}:::${key}`;
  }

  set(params: MemorySetParams, authorInfo?: { id?: string; name?: string }): MemorySetResult {
    const namespace = params.namespace ?? "global";
    const internalKey = this.makeKey(namespace, params.key);
    const existing = this.entries.get(internalKey);
    const now = new Date().toISOString();

    let expiresAt: string | undefined;
    if (params.ttlSeconds && params.ttlSeconds > 0) {
      expiresAt = new Date(Date.now() + params.ttlSeconds * 1000).toISOString();
    }

    const version = (existing?.version ?? 0) + 1;
    const entry: MemoryEntry = {
      key: params.key,
      value: params.value,
      namespace,
      authorId: authorInfo?.id,
      authorName: authorInfo?.name,
      tags: params.tags ?? [],
      version,
      createdAt: existing?.createdAt ?? now,
      updatedAt: now,
      ttlSeconds: params.ttlSeconds,
      expiresAt,
    };

    this.entries.set(internalKey, entry);
    this.emitEvent({ type: "memory.entry_set", entry, at: now });

    return { success: true, entry };
  }

  get(params: MemoryGetParams): MemoryGetResult {
    const namespace = params.namespace ?? "global";
    const internalKey = this.makeKey(namespace, params.key);
    const entry = this.entries.get(internalKey);

    if (!entry) return { found: false, entry: null };

    // Check expiration
    if (entry.expiresAt && new Date(entry.expiresAt).getTime() <= Date.now()) {
      this.delete(params);
      return { found: false, entry: null };
    }

    return { found: true, entry };
  }

  query(params: MemoryQueryParams): MemoryQueryResult {
    this.sweepExpired();
    let list = Array.from(this.entries.values());

    if (params.namespace) {
      list = list.filter((e) => e.namespace === params.namespace);
    }
    if (params.query) {
      const q = params.query.toLowerCase();
      list = list.filter((e) => e.key.toLowerCase().includes(q));
    }
    if (params.tags && params.tags.length > 0) {
      list = list.filter((e) => params.tags!.some((t) => e.tags.includes(t)));
    }

    const total = list.length;
    const offset = params.offset ?? 0;
    const limit = params.limit ?? 50;
    const entries = list.slice(offset, offset + limit);

    return { entries, total };
  }

  delete(params: MemoryDeleteParams): MemoryDeleteResult {
    const namespace = params.namespace ?? "global";
    const internalKey = this.makeKey(namespace, params.key);
    const existed = this.entries.delete(internalKey);
    const now = new Date().toISOString();

    if (existed) {
      this.emitEvent({
        type: "memory.entry_deleted",
        key: params.key,
        namespace,
        at: now,
      });
    }

    return { success: true, deleted: existed };
  }

  clear(namespace?: string): number {
    let count = 0;
    const now = new Date().toISOString();
    if (!namespace) {
      count = this.entries.size;
      this.entries.clear();
      this.emitEvent({ type: "memory.cleared", at: now });
    } else {
      for (const [k, entry] of this.entries.entries()) {
        if (entry.namespace === namespace) {
          this.entries.delete(k);
          count++;
        }
      }
      this.emitEvent({ type: "memory.cleared", namespace, at: now });
    }
    return count;
  }

  sweepExpired(): number {
    const now = Date.now();
    let swept = 0;
    for (const [k, entry] of this.entries.entries()) {
      if (entry.expiresAt && new Date(entry.expiresAt).getTime() <= now) {
        this.entries.delete(k);
        swept++;
      }
    }
    return swept;
  }

  subscribe(listener: (event: MemoryLifecycleEvent) => void): () => void {
    this.on("event", listener);
    return () => this.off("event", listener);
  }

  private emitEvent(event: MemoryLifecycleEvent): void {
    this.emit("event", event);
    this.emit(event.type, event);
  }
}
```

#### 4.2 New File: `apps/agent-host/src/agents/telemetry.ts`
Implement `TelemetryTracker`:

```ts
import type { SubagentTelemetry } from "@protocol/subagents";

export interface TurnMetricsInput {
  promptTokens: number;
  completionTokens: number;
  turnLatencyMs: number;
  toolLatencyMs?: number;
  costPer1kInput?: number;
  costPer1kOutput?: number;
}

export class TelemetryTracker {
  private readonly agentMetrics = new Map<string, {
    promptTokens: number;
    completionTokens: number;
    totalTokens: number;
    estimatedCostUsd: number;
    turnCount: number;
    turnLatencies: number[];
    toolDurationMs: number;
    startTime: number;
  }>();

  initAgent(subagentId: string): void {
    if (!this.agentMetrics.has(subagentId)) {
      this.agentMetrics.set(subagentId, {
        promptTokens: 0,
        completionTokens: 0,
        totalTokens: 0,
        estimatedCostUsd: 0,
        turnCount: 0,
        turnLatencies: [],
        toolDurationMs: 0,
        startTime: Date.now(),
      });
    }
  }

  recordTurn(subagentId: string, input: TurnMetricsInput): SubagentTelemetry {
    this.initAgent(subagentId);
    const m = this.agentMetrics.get(subagentId)!;

    m.promptTokens += input.promptTokens;
    m.completionTokens += input.completionTokens;
    m.totalTokens += (input.promptTokens + input.completionTokens);
    m.turnCount += 1;
    m.turnLatencies.push(input.turnLatencyMs);
    if (input.toolLatencyMs) m.toolDurationMs += input.toolLatencyMs;

    const inputCost = (input.promptTokens / 1000) * (input.costPer1kInput ?? 0);
    const outputCost = (input.completionTokens / 1000) * (input.costPer1kOutput ?? 0);
    m.estimatedCostUsd += (inputCost + outputCost);

    return this.getTelemetry(subagentId);
  }

  getTelemetry(subagentId: string): SubagentTelemetry {
    const m = this.agentMetrics.get(subagentId);
    if (!m) {
      return {
        promptTokens: 0,
        completionTokens: 0,
        totalTokens: 0,
        estimatedCostUsd: 0,
        tokensPerSecond: 0,
        turnCount: 0,
        avgTurnLatencyMs: 0,
        lastTurnLatencyMs: 0,
        p95TurnLatencyMs: 0,
        totalDurationMs: 0,
        toolDurationMs: 0,
      };
    }

    const totalDurationMs = Date.now() - m.startTime;
    const avgTurnLatencyMs = m.turnLatencies.length > 0
      ? m.turnLatencies.reduce((a, b) => a + b, 0) / m.turnLatencies.length
      : 0;
    const lastTurnLatencyMs = m.turnLatencies[m.turnLatencies.length - 1] ?? 0;

    // Calculate p95
    const sorted = [...m.turnLatencies].sort((a, b) => a - b);
    const p95Idx = Math.floor(sorted.length * 0.95);
    const p95TurnLatencyMs = sorted[p95Idx] ?? lastTurnLatencyMs;

    const tokensPerSecond = totalDurationMs > 0 ? (m.totalTokens / (totalDurationMs / 1000)) : 0;

    return {
      promptTokens: m.promptTokens,
      completionTokens: m.completionTokens,
      totalTokens: m.totalTokens,
      estimatedCostUsd: m.estimatedCostUsd,
      tokensPerSecond: Math.round(tokensPerSecond * 100) / 100,
      turnCount: m.turnCount,
      avgTurnLatencyMs: Math.round(avgTurnLatencyMs),
      lastTurnLatencyMs: Math.round(lastTurnLatencyMs),
      p95TurnLatencyMs: Math.round(p95TurnLatencyMs),
      totalDurationMs,
      toolDurationMs: m.toolDurationMs,
    };
  }
}
```
